# DESTINY — пентест Web, API и AI-систем

Статический сайт [destiny.by](https://destiny.by/) из репозитория [Vadimohka/destiny.by](https://github.com/Vadimohka/destiny.by). HTML, CSS и JavaScript без клиентского фреймворка. Для подготовки метаданных и текстовых представлений достаточно стандартной библиотеки Python 3. Готовый PDF хранится в репозитории; его пересборка использует отдельные зависимости.

## Страницы

| Файл | Назначение |
| --- | --- |
| `index.html` | Краткое предложение, четыре направления и переходы к подробностям |
| `web-pentest.html` | Пентест веб-приложений, SaaS и личных кабинетов |
| `api-pentest.html` | Проверка API и интеграций |
| `ai-security.html` | Безопасность LLM, RAG и AI-агентов |
| `retest.html` | Проверки релизов и ретест исправлений |
| `approach.html` | Этапы работы и ответы на вопросы |
| `report-example.html` | Демонстрационный отчёт Web/API и AI |
| `contact.html` | Прямые ссылки на LinkedIn и электронную почту |
| `privacy.html`, `404.html` | Конфиденциальность и страница ошибки |

Услуги, процесс и контакты имеют самостоятельные адреса. Общая визуальная система задаётся в `assets/styles.css` и `assets/documents.css`; контакты используют `assets/contact.css`. Навигация находится в `assets/site.js`. Страница с примером отчёта содержит вымышленные сценарии, а не результаты клиентского проекта.

## Языки

Русская версия находится в корне сайта, белорусская — в [`/be/`](https://destiny.by/be/). Все десять HTML-страниц имеют белорусские варианты в `be/`. Переключатель языка ведёт на соответствующую страницу другой версии; обычные ссылки работают и без JavaScript. Внутренние ссылки белорусской версии сохраняют язык, а общие стили, скрипты, изображения и шрифты берутся из `assets/`.

`assets/localization.css` оформляет переключатель «РУС / БЕЛ». JavaScript сохраняет якорь раздела при смене языка и переводит доступные подписи мобильного меню. GitHub Pages обслуживает отсутствующие адреса одним корневым `404.html`; `assets/404-locale.js` показывает белорусские подписи и ссылки для путей `/be/`, сохраняя исходный URL и HTTP 404. Без JavaScript переключатель ведёт на готовую `be/404.html`.

У белорусских страниц задан `lang="be"`, собственные канонические URL и Open Graph locale `be_BY`. Для пар страниц генератор создаёт взаимные `hreflang="ru"`, `hreflang="be"` и `hreflang="x-default"`; по умолчанию используется русский адрес. Страницы ошибки сохраняют `noindex` без canonical и поисковых языковых альтернатив. Общая карта сайта содержит восемь индексируемых страниц каждого языка.

## Контакты

Владелец указал два канала: [LinkedIn](https://www.linkedin.com/in/vadimohka/) и [security@destiny.by](mailto:security@destiny.by). Ссылки находятся в `contact.html` и общем подвале.

Сайт не содержит формы отправки и не обращается к почтовому посреднику. Ссылка LinkedIn открывает указанный профиль; обычный `mailto:` передаёт адрес почтовому приложению посетителя. Сайт не формирует текст письма и не отправляет сообщение от имени посетителя. Информация о переписке и внешних каналах находится в `privacy.html`.

## Редактирование и SEO

В обеих языковых версиях заголовки, короткие подзаголовки, подписи подвала и краткие формулировки в таблице охвата отчёта оформляются без завершающих точек, в том числе перед переносом строки внутри заголовка. В обычных абзацах, описаниях и ответах FAQ сохраняется пунктуация предложений. Это же правило применяется к заголовкам и подписям карточек для социальных сетей.

Исходный текст редактируется в HTML соответствующего языка. Заголовки страниц, descriptions, канонические пути и список индексируемых страниц русской версии задаются в `seo/site.json`. Поле `localizations` подключает `seo/be.json`, который переопределяет язык, пути, тексты метаданных и услуги для белорусской версии; общие настройки домена, контактов и логотипа наследуются. Услуги связаны с собственными HTML-файлами, FAQ извлекается из `approach.html` и `be/approach.html`. Email и LinkedIn в конфигурации должны совпадать с опубликованными ссылками на страницах контактов. Личный профиль LinkedIn отражён как связанная ссылка ContactPage, а не как `sameAs` организации.

После изменения страниц:

```bash
python3 scripts/build_discovery.py
```

Генератор обновляет метаданные в `<head>`, JSON-LD, общие `sitemap.xml` и `robots.txt`, а также `ai.json`, `llms.txt`, `llms-full.txt` и Markdown-представления индексируемых страниц для каждого языка. Белорусские текстовые и JSON-LD представления находятся в `be/`; их ссылки и идентификаторы сущностей используют белорусские адреса. При содержательном обновлении страницы поправьте её `updated` в конфигурации соответствующего языка; дата не меняется автоматически при технической публикации.

Сохраните исходники и сгенерированные файлы в одном коммите. В Actions выполняется `python3 scripts/build_discovery.py --check`: публикация останавливается при несовпадении представлений, сломанных внутренних ссылках (включая изображения `srcset`), неверном языке HTML, отсутствии языковой пары, ошибочных ссылках или отметке текущего языка в переключателе, а также несогласованных метаданных. `--check` проверяет обе локализации и ничего не записывает.

Главная, четыре услуги, подход, пример отчёта и контакты обоих языков включены в sitemap с языковыми альтернативами. Страницы конфиденциальности и ошибки обоих языков имеют `noindex` и исключены из карты. Для отсутствующих адресов GitHub Pages возвращает штатный HTTP 404.

`ai.json` публикует стандартный Schema.org JSON-LD с устойчивыми идентификаторами компании, сайта, услуг и страниц. Это выбранный для сайта адрес экспорта. `llms.txt` и Markdown дополняют HTML для поддерживающих их клиентов. В них сохранены опубликованные прямые контакты. Наличие этих файлов не подтверждает индексацию или цитирование поисковиками. Подробные источники — в [исследовании SEO/GEO](research/seo-geo-2026-10-30.md).

## Пример отчёта в PDF

`report-example.html` содержит прямую ссылку на `assets/reports/destiny-pentest-report-example.pdf`. Скачивание не зависит от JavaScript и диалога печати браузера. Путь задан также в `seo/site.json`: генератор добавляет PDF в `Report.encoding` и `<link rel="alternate" type="application/pdf">`, а ссылка сохраняется в текстовой версии отчёта.

HTML-пример отчёта переведён в `be/report-example.html`. Готовый PDF остаётся русскоязычным: это явно указано у ссылки на скачивание в белорусской версии и в её метаданных (`pdfLanguage: "ru"` в `seo/be.json`). Обе версии используют один PDF и одну миниатюру.

PDF собирается из содержания `report-example.html`, шрифтов и изображений в `assets/`. Для обновления после правок текста:

```bash
python3 -m pip install reportlab fonttools Pillow
python3 scripts/build_report_pdf.py
python3 scripts/build_discovery.py
```

Перед публикацией проверьте разбивку страниц в готовом PDF. Миниатюра `assets/reports/destiny-pentest-report-cover.webp` экспортируется отдельно из первой страницы с помощью Poppler и Pillow, размер — 420×594. При изменении обложки обновите и миниатюру. PDF и миниатюра публикуются вместе с остальными ассетами; Pages не пересобирает документ при каждом запуске.

## Публикация

Push в `main` запускает `.github/workflows/pages.yml`. Workflow проверяет метаданные, собирает `_site` и публикует его в среду `github-pages`. HTML и Markdown берутся из явных списков обеих конфигураций через общий `load_configs()`; вложенные пути `be/` копируются с сохранением структуры. Абсолютные пути и выход через `..` запрещены. В артефакт также входят `assets/`, файлы обнаружения каждого языка, `CNAME`, `.nojekyll` и публичный ключ IndexNow. Исходники генератора, `seo/`, README, исследование и локальная среда предпросмотра не публикуются.

Основной домен — `destiny.by`. Конфигурация Pages, домена и HTTPS находится в настройках репозитория. [GitHub: публикация через Actions](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages), [настройка домена](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site).

После успешной публикации `scripts/notify_indexnow.py` уведомляет [IndexNow](https://www.indexnow.org/documentation) об индексируемых HTML-адресах обоих языков. Перед POST он сверяет опубликованный `indexnow-key.txt`. Этот постоянный публичный ключ не является паролем и не должен меняться при каждой сборке. Сетевой сбой уведомления не отменяет публикацию. Для проверки списка без отправки:

```bash
python3 scripts/notify_indexnow.py --dry-run
```

Для наблюдения за поисковой индексацией владелец может подтвердить домен в Google Search Console и Bing Webmaster Tools и подать `https://destiny.by/sitemap.xml`. В репозитории нет фиктивных токенов подтверждения.

## Дизайн и материалы

Сохранены чёрно-красная палитра, цифровой арт и геометрический логотип DESTINY без точки. Шрифты Oswald и Onest находятся в `assets/fonts/` вместе с OFL-лицензиями. Основное изображение — `assets/blackwall-entity-v4.webp`; тематические изображения внутренних страниц находятся в `assets/visuals/`. Стиль и движение этих вступительных блоков заданы в `assets/page-hero.css` и `assets/page-hero.js`. Анимация учитывает системное уменьшение движения и экономию трафика, останавливается вне экрана или в скрытой вкладке. Элементов управления анимацией на странице нет.

Белорусская карточка для социальных сетей — `assets/social-card-be.png` (1200×630), её векторный исходник — `assets/social-card-be.svg`. Текст локализован, исходные фон и логотип сохранены. Пересборка: `python3 scripts/build_social_card_be.py`; нужны `fonttools` и Node.js с `sharp`. Готовые файлы хранятся в репозитории, поэтому обычная публикация Pages не требует этих зависимостей.

Четыре отдельных сюжета `blackwall-{web,api,ai,retest}-v12.webp` используются в героях услуг, а версии `-small.webp` — в компактных баннерах карточек главной. Файлы 1600×900 и 800×450 имеют собственные композиции; промпты и происхождение записаны в `research/banner-art-v12.json`. Размещение и кадрирование задаёт `assets/banners.css`.

Дополнительные эффекты находятся в `assets/ambient.css` и `assets/ambient.js`: `data-reveal` включает однократное появление, `data-ambient-banner` — движение декоративного `picture`, `data-ambient-card` — световой проход по границе при наведении или фокусе. Контент виден без JavaScript. Короткое смещение запускается только у одного видимого баннера за раз; текст, таблицы и содержимое PDF не анимируются.
