Каналы связи

Связаться с DESTINY можно через LinkedIn или по адресу security@destiny.by. На сайте нет формы отправки сообщений. Ссылка электронной почты открывает вашу почтовую программу; письмо отправляете вы.

Данные обращения

Сведения из вашего сообщения нужны для ответа и обсуждения работы. Для первого разговора достаточно описания продукта, задачи и желаемого срока.

Пароли, токены, закрытые документы и персональные данные клиентов в первом обращении не нужны. Способ передачи материалов для проверки согласуем отдельно.

Внешние сервисы

Переписка в LinkedIn и по электронной почте происходит в выбранном вами сервисе. На неё распространяются условия этого сервиса. На сайте нет рекламных пикселей и подключённой веб-аналитики.

Сайт размещён на GitHub Pages. Сведения об обработке данных при посещении сайта опубликованы в документации GitHub Pages.

Вопросы о данных

По вопросам обращения, исправления или удаления переданных сведений напишите на security@destiny.by. Укажите, когда и через какой канал вы связывались с нами.
